# Portfólio Raquel

Crie um site-portfólio profissional para Raquel Villas, profissional de Marketing B2B, com experiência em Inbound Marketing, Conteúdo, Geração de Demanda, CRM, E-mail Marketing, Social Media, Landing Pages, Eventos e projetos digitais.

O objetivo do site é funcionar como um portfólio profissional para apresentação a recrutadores, gestores de marketing e potenciais oportunidades profissionais.

IMPORTANTE:

Este não deve parecer um currículo online tradicional nem um simples catálogo de peças de design.

O site deve comunicar que Raquel é uma profissional de marketing generalista com visão estratégica e capacidade de executar projetos de ponta a ponta.

A narrativa central deve ser:

ESTRATÉGIA → CONTEÚDO → EXECUÇÃO → RESULTADO

A ideia é mostrar que ela consegue atuar em diferentes pontos da jornada de marketing, desde geração de demanda até relacionamento, retenção e construção de marca.

==================================================

1. POSICIONAMENTO

==================================================

Nome:

Raquel Villas

Headline principal:

Marketing B2B · Inbound · Conteúdo · Geração de Demanda

Posicionamento:

"Profissional de marketing com experiência em estratégias de geração de demanda, inbound, conteúdo B2B, relacionamento, campanhas digitais e projetos de comunicação."

O texto pode ser refinado para ficar mais natural e sofisticado, mas NÃO deve exagerar senioridade, resultados ou competências que não estejam comprovados.

O site deve transmitir:

- pensamento estratégico;

- visão de funil;

- capacidade de execução;

- domínio de conteúdo;

- familiaridade com ferramentas digitais;

- autonomia;

- curiosidade e experimentação;

- capacidade de conectar diferentes canais em uma mesma estratégia.

==================================================

3. DIREÇÃO VISUAL

==================================================

Usar como referência visual o screenshot fornecido do portfólio atual.

A estética deve ser:

- editorial;

- minimalista;

- sofisticada;

- profissional;

- contemporânea;

- com inspiração em portfólios de profissionais criativos e estrategistas;

- bastante espaço em branco;

- tipografia com personalidade;

- poucos elementos decorativos;

- hierarquia visual muito clara.

Evitar:

- aparência de template genérico;

- excesso de cards;

- gradientes muito chamativos;

- excesso de cores;

- ilustrações genéricas de banco de imagens;

- ícones desnecessários;

- animações exageradas;

- estética "startup SaaS" genérica.

A identidade deve parecer mais próxima de uma publicação editorial / estúdio criativo do que de uma landing page comercial.

==================================================

4. TIPOGRAFIA

==================================================

Usar combinação de:

- fonte serifada elegante para títulos e elementos de destaque;

- fonte monoespaçada ou sans-serif com aparência técnica/editorial para navegação, labels e informações secundárias.

A tipografia deve ser um dos elementos principais da identidade.

Criar contraste entre:

- títulos grandes;

- textos corridos menores;

- labels em caixa alta;

- pequenas informações técnicas.

==================================================

5. PALETA

==================================================

Partir de uma base neutra:

- off-white / branco quebrado para fundo;

- preto ou grafite para textos;

- verde escuro/desaturado como cor de destaque;

- cinzas neutros para elementos secundários.

A paleta deve ser discreta.

Não usar muitas cores.

A cor de destaque deve aparecer principalmente em:

- links;

- hover;

- pequenos detalhes;

- CTAs;

- indicadores de categoria.

==================================================

14. RESPONSIVIDADE

==================================================

O site deve ser completamente responsivo.

Desktop:

- layout amplo;

- bastante espaço em branco;

- navegação horizontal;

- projetos apresentados de forma editorial.

Tablet:

- adaptar grids;

- preservar hierarquia.

Mobile:

- menu hamburger;

- tipografia ajustada;

- imagens responsivas;

- cards empilhados;

- CTAs fáceis de tocar;

- não permitir overflow horizontal.

==================================================

15. INTERAÇÕES

==================================================

Usar animações discretas.

Exemplos:

- fade-in suave;

- pequenos movimentos no hover;

- underline animado nos links;

- transições de página;

- imagens aparecendo suavemente durante o scroll.

NÃO usar:

- parallax excessivo;

- animações exageradas;

- elementos pulando;

- loading screens desnecessárias.

O conteúdo deve continuar sendo o protagonista.

==================================================

- profissional;

- natural;

- humano;

- contemporâneo.

Evitar clichês como:

"criativa por natureza"

"faço acontecer"

"pensar fora da caixa"

"soluções inovadoras que geram resultados incríveis"
